## 功能亮点

- **多组协作**：不同汉化组拥有独立空间，按成员分工管理权限与任务。
- **连载管理**：按漫画、章节组织项目，记录各个汉化环节的进度、时间与耗时。
- **在线翻校**：在浏览器中看图翻译、切换校对模式，配合术语库、快捷字符、特殊标记与结构化注释。
- **嵌字交付**：PSD 压缩上云，集中上传和交付章节成稿。
- **在线监修**：直接在成稿上框选批注，让修改意见对应到具体位置。
- **漫画归档**：导出漫画 ZIP 归档，并在漫画广场浏览已归档作品。
