## 结构与接口

- 业务按 `routes/**/business` 内聚，跨页面共同业务归共同父 route；通用实现位于 `shared`。
- TanStack 文件路由替换原路由表，集中身份恢复与在线租约；保留旧 URL、字符串 search 和持久化键。
- 身份代次约束异步请求、邮件缓存与上传任务，旧身份结果不得写入新会话。
- 漫画详情、上传、翻校编辑器和邀请界面按实际职责拆分；全仓 400 行、命名、导出和依赖边界检查通过。
- 必需动作和受控输入改为必填；确认框及分页使用明确模式，空团队和失效身份显式呈现。详见[接口审查](interface-audit.md)。
- [实施入口清单](../migration/implementation-map.csv)覆盖全部 480 个基线文件；`actual_entry` 是当前主要入口，不能代替拆分后全部文件的行为审查。拆分目标的具体名字以源码为准，原 [设计清单](../migration/file-map.csv)保留设计意图。
- 全部生产静态运行时 import 的临时 AST 检查未发现循环；独立于项目依赖边界检查。
